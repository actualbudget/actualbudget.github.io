Managing Multi-User Support

caution

This feature requires you to have set up an OpenID Provider. The usernames which people will log into your Actual instance will be fetched from the provider.

User Directory​

Use this page to manage users who have access to the Actual Budget instance.

To access the User Directory page, access the menu from the server:

Users can be added, disabled, enabled, removed from this page:

There are two user roles Basic or Admin.

  • The Basic role: Users with the Basic role can create new budgets and collaborate on budgets made by others. This role is ideal for users who primarily need to manage and participate in shared budget activities.

  • The Admin role: This role can do everything the Basic user role can. It can also add new users to the user directory and allow all users to access budget files. The role can assign ownership of a budget to another person, ensuring efficient budget management.
